# Start Here

This page tells you how to open Delphic AI.

You do not need to know coding.

## What You Need

You need:

1. Python
2. An AI key

Python helps the app run.

The AI key helps the tutor answer you.

## Step 1: Get Python

If Python is not on your computer, get it here:

```text
https://www.python.org/downloads/
```

On Windows, look for this box:

```text
Add Python to PATH
```

Click the box.

Then finish installing Python.

## Step 2: Open The App

If you are on a Mac, double-click:

```text
run_mac.command
```

If you are on Windows, double-click:

```text
run_windows.bat
```

## Step 3: Wait

The first time may take a few minutes.

That is normal.

The app is getting ready.

## Step 4: Use The App

The app should open this page:

```text
http://127.0.0.1:5001
```

If it does not open by itself, copy that link into your browser.

That browser page is the app.

The Markdown file is only the directions.

## Step 5: Add The AI Key

When the app opens, a box will pop up.

The box asks you to choose an AI provider.

You can pick:

- Groq
- OpenAI
- Anthropic
- Google Gemini
- Mistral
- Together AI
- xAI
- DeepSeek

Then paste your API key.

The key is used to answer questions.

## Which AI Is Picked?

Each AI provider has a model already picked for it.

I picked models that try to be:

- Good at math
- Good at science
- Not the most expensive choice

That means the app tries to use a smart helper without picking the biggest and priciest helper first.

## How To Stop The App

Closing the browser tab does not stop the app.

To stop it:

1. Click the Terminal window.
2. Press `Control + C`.

## If It Does Not Work

Try this:

1. Close the app window.
2. Open it again.
3. Check that Python is installed.
4. Check that you pasted the right AI key.
