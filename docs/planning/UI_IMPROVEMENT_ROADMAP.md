# UI Improvement Roadmap

This roadmap lists UI improvements from most important to least important. The goal is to make the app feel cleaner, more polished, and more demo-ready without changing the backend or AI behavior.

## 1. Clean Up The Sidebar

### Why This Comes First

The sidebar is one of the first things users see. If it feels crowded, the whole app feels less polished.

### What To Improve

- Make sidebar spacing more consistent.
- Group related actions together.
- Make `New Chat`, `Download Chat`, and `Clear Chat` feel like one clean system.
- Reduce visual noise from too many button styles.
- Make session history easier to scan.

### Expected Impact

This will make the app feel more organized and professional right away.

## 2. Standardize Buttons

### Why This Is Important

Right now, buttons can feel like they come from different design systems. A product manager will notice that quickly.

### What To Improve

- Create consistent button sizes.
- Use consistent border radius.
- Use consistent hover states.
- Make destructive actions like `Clear Chat` look different from normal actions.
- Make feature actions like `Practice Similar Problem` visible but not messy.

### Expected Impact

The app will feel more intentional and less like separate features were added one at a time.

## 3. Polish The Chat Bubbles

### Why This Matters

The chat area is the main product experience. If the bubbles look good, the whole app feels better.

### What To Improve

- Improve spacing inside assistant and student bubbles.
- Make message width feel balanced on large screens.
- Make timestamps less distracting.
- Make copy and practice actions feel attached to the message.
- Improve math-heavy response readability.

### Expected Impact

The app will feel more like a real AI tutor and less like a basic chat demo.

## 4. Improve The Input Area

### Why This Matters

The input area is where the student spends the most time interacting with the app.

### What To Improve

- Refine the text pill spacing.
- Make the send button feel perfectly placed.
- Make the Step-by-Step toggle feel connected to the input.
- Make the disclaimer quieter.
- Make the bottom area feel clean and stable on mobile.

### Expected Impact

The app will feel smoother and easier to use.

## 5. Reduce Emoji Noise

### Why This Matters

Emojis can make the app friendly, but too many can make it feel less professional.

### What To Improve

- Keep a few helpful emojis.
- Remove emojis that are decorative but not useful.
- Make the welcome message calmer.
- Use text hierarchy instead of emojis to guide attention.

### Expected Impact

The app will feel more mature while still being friendly for students.

## 6. Improve Typography

### Why This Matters

Good typography makes an app feel polished even before users notice why.

### What To Improve

- Make headings, labels, buttons, and body text feel more consistent.
- Improve line-height for long AI responses.
- Make small labels easier to read.
- Avoid text feeling cramped in compact areas.

### Expected Impact

The app will feel easier to read and more professional.

## 7. Add Neon Theme

### Why This Comes After Typography

The neon theme should be fun and colorful, but it should sit on top of a clean base UI. If the layout, buttons, and typography are not polished first, the neon theme could make the app feel messy instead of exciting.

### What To Improve

- Add a third theme option after light and dark.
- Use brighter accent colors for a more playful look.
- Add controlled glow effects to important UI elements.
- Keep text readable and not too bright.
- Make sure neon mode still feels like a study tool, not a distracting game screen.

### Expected Impact

This will make the app feel more fun and memorable while keeping the normal light and dark themes available.

## 8. Improve Mobile Layout

### Why This Comes Later

Desktop polish and theme structure should come first because that is likely where demos happen. Mobile still matters, but it should follow the main layout cleanup and theme decisions.

### What To Improve

- Check sidebar behavior on small screens.
- Make the input area comfortable on phones.
- Make buttons stack cleanly.
- Make chat bubbles fit without awkward overflow.

### Expected Impact

The app will feel more complete across devices.

## 9. Final Visual Pass

### Why This Comes Last

This is where small details are fixed after the bigger layout decisions are done.

### What To Improve

- Tune shadows.
- Tune borders.
- Tune hover states.
- Check light mode and dark mode side by side.
- Remove anything that feels inconsistent.

### Expected Impact

This is the final polish step that can move the UI closer to demo-ready.

## Recommended Order

1. Clean up the sidebar. Done.
2. Standardize buttons. Done.
3. Polish the chat bubbles. Done.
4. Improve the input area. Done.
5. Reduce emoji noise. Done.
6. Improve typography. Done.
7. Add neon theme. Done.
8. Improve mobile layout. Done.
9. Final visual pass. Done.
